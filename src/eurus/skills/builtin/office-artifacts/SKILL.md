# Office Artifact Skill

Use for Word documents, spreadsheets, reports, proposals, and operational workbooks.

## Word documents

- Use a descriptive title, a short opening summary, and headings that describe the point of each section.
- Prefer short paragraphs, meaningful lists, and consistent terminology.
- Distinguish decisions, actions, risks, assumptions, and evidence.
- Preserve the author's intended meaning; mark unknown facts as needing verification rather than inventing details.

## Excel workbooks

- Make each worksheet answer a clear question. Use concise sheet names, descriptive column headers, consistent units, and one record per row.
- Keep source values distinct from assumptions and calculated outputs. Explain metrics and date ranges.
- Use filters, frozen headers, readable widths, and restrained header styling.
- Avoid merged cells in data tables. Do not fabricate values to fill gaps. Treat user-provided text as text, not executable spreadsheet formulas.

## Delivery review

Check consistency, completeness, labels, spelling, units, and audience fit. Report any assumptions or missing source data with the deliverable.
