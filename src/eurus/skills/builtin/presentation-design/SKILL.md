# Presentation Design Skill

Use when building a PowerPoint deck or slide outline. For HTML previews, also load `html-layout-canvas`.

## Narrative

- Start with the audience, decision, and desired outcome.
- Give each slide one central point expressed as a claim-style title, not a generic topic label.
- Sequence slides as context, insight, evidence, implication, and next action when that narrative fits the brief.
- Separate sourced facts, estimates, assumptions, and recommendations. Never invent statistics, customer quotes, or citations.
- Prefer concise wording and useful specifics over vague business language.

## Visual system

- Use a restrained palette, consistent typography, and generous whitespace.
- Use charts for quantitative comparisons, tables for exact values, diagrams for systems, and timelines for sequence.
- Avoid paragraphs on slides; move supporting detail to notes or an accompanying document when supported.
- Use callouts sparingly for decisions, risks, or memorable findings.
- Keep titles, body text, alignment, spacing, and slide numbers consistent, while varying composition when the content requires it.
- Check that each slide is legible at presentation distance and that no text or shapes are clipped.

## Final quality gate

Before delivery, check narrative continuity, factual support, slide-to-slide repetition, typography hierarchy, contrast, density, and whether the deck answers the original brief. State assumptions that need confirmation.
